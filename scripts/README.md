# Scripts

This directory contains utility scripts for development, deployment, testing, and maintenance.

## Directory Structure

- `dev/` - Development utilities (code formatting, linting, testing helpers)
- `deploy/` - Deployment scripts and automation
- `test/` - Test execution and validation scripts
- `utils/` - General purpose utility scripts

## Common Scripts

- `dev/setup.sh` - Development environment setup
- `dev/lint.sh` - Code linting
- `dev/format.sh` - Code formatting
- `deploy/build.sh` - Build Docker images or binaries
- `deploy/k8s-deploy.sh` - Deploy to Kubernetes cluster
- `test/run-all.sh` - Run all test suites
- `utils/health-check.sh` - System health verification
